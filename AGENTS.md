# AGENTS.md

Instructions for AI coding agents working in this repo live in
**[CLAUDE.md](CLAUDE.md)** — read it first. The essentials:

- Everything (STLs, previews, index.html) is **generated** from `case.py` — never
  edit generated files by hand; regenerate with `make`. All builds run in Docker;
  **nothing is installed on the host**, ever.
- The camera's verified geometry (41 x 41 x 58 mm, built-in stand, lying pose) and
  the approximate camera model are defined in `case.py` and documented in CLAUDE.md.
  Do not re-derive them; change them only with a cited source.
- Two variants, `friction` and `snap`, are both kept and both regenerated by every
  `make`. Tune per printer with env parameters (`make VARIANTS=snap SNAP=0.25`),
  not by editing constants.
- Run `make check` (both variants) before committing, and commit regenerated
  outputs together with the code change.
- Keep README.md, CLAUDE.md and this file in sync with `case.py`.
